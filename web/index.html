棋局小记 ＋

黑白交替落子。棋子上下左右相连形成一块；相邻空点称为「气」。没有气的棋块会被提走，不能自杀落子。

采用简单劫规则，不能立即还原上一手之前的局面。双方连续停一手后结束；白棋贴 6.5 目。

终局以盘面棋子和围住的空点估算面积，不自动判定死子。请先把需要提走的棋子提净，再停一手。这是练习用的简化计分。

CPU 使用基础启发式策略，适合入门练习。三种棋风是游戏化预设，可随时切换，从 CPU 的下一手生效。悔棋会撤回你与 CPU 的最近一轮落子。

黑白之间，自有天地。棋局自动保存在此浏览器
